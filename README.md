# نوفا — صفحة بداية بسيطة

صفحة بداية عربية ومشهد طريق متحرك يضم سيارة نيون وروابط منصات التواصل.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث.

## ملاحظات

- البحث محلي في أسماء منصات التواصل فقط؛ لا تُرسل عبارة البحث إلى محرك خارجي ولا تُحفظ.
- روابط المنصات تفتح عند النقر، وتتم أي عملية تسجيل دخول لدى المنصة الرسمية.
- لا يحفظ الموقع حسابات أو كلمات مرور أو ملفات، ولا يرسلها إلى خادم.
- انقر لوحة «F ♥ W» للانتقال إلى حقل البحث، أو انقر جسم السيارة لفتح الأبواب وإغلاقها.
- تتضمن السيارة إضاءة أمامية وخلفية متحركة وجناحاً خلفياً.
