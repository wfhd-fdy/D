# نوفا — صفحة بداية بسيطة

صفحة بداية عربية بحقل بحث مباشر ومشهد طريق متحرك يضم سيارة نيون.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث.

## ملاحظات

- البحث يفتح Brave Search، بينما يمكن إدخال عنوان موقع للانتقال إليه مباشرة.
- انقر لوحة «أبحث / F-w» للانتقال إلى حقل البحث، أو انقر جسم السيارة لفتح الأبواب وإغلاقها.
- تتضمن السيارة إضاءة أمامية وخلفية متحركة وجناحاً خلفياً.
